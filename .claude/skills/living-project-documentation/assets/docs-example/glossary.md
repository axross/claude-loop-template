# Glossary

**Run** — a run creates a **Job**, one execution of a Job Template. See
[what a manual or scheduled run returns](./scheduling/jobs.md#creating-a-job).

**Retries remaining** — the dashboard label for retries available to the current
job. See [when a failed attempt is retried and what happens at exhaustion](./scheduling/outcomes.md#attempts-and-retries).

**Job output** — the result a job produced. See
[how to retrieve it after the job record is pruned](./scheduling/jobs.md#output-and-pruning).
