# Contributing

Choose the part of your change you are working on:

- [Configure a development agent](./agents/index.md) — Start a session, choose a subagent, configure hooks or update a skill.
- [Deliver a change](./change-delivery.md) — Work on a branch, address a review finding and decide when the pull request is ready.
- [Place and maintain documentation](./documentation.md) — Identify the page that should own a decision and connect it to its readers.
- [Verify a documentation change](./verify-documentation.md) — Check the bundle in the checkout and test the routes that need to work in a standalone copy.

Before publishing or monitoring a pull request, check [which actions the maintainer authorized](../governance/delivery-authorization.md).

Previous editions collected these instructions in the guides to [sessions](../operations/agent-sessions.md),
[skills](../operations/agent-skills.md), [development workflow](../operations/development-workflow.md)
and [documentation conventions](../conventions/documentation.md). Their published bookmarks lead to the corresponding procedures.
